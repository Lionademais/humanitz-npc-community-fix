HumanitZ - NPC Community Dedicated Fix - Client
================================================

PORTUGUES
---------
Faz o recrutamento e o gerenciamento de NPCs (Comunidade, versao 1.1) funcionarem em servidor dedicado.
O cliente e so um pak: nao altera o executavel do jogo.

Instalacao
- Vortex: instale pelo botao "Mod Manager Download" (extensao "HumanitZ Vortex Extension").
- Manual: copie NPCCommunityFix_Client_P.pak para ...\HumanitZ\HumanitZ\Content\Paks\~mods\
  (crie a pasta ~mods se ela nao existir).

Requisitos
- O servidor precisa da parte de servidor deste mod, na mesma versao.
- Single-player e partidas hospedadas por voce funcionam normalmente com o mod instalado.

IMPORTANTE
- Desative/remova o mod antes de entrar em servidores sem ele (oficiais ou de terceiros): o mod muda a forma
  como os dados de comunidade sao replicados e a conexao com um servidor sem o mod pode falhar.
- Atualizacoes do jogo podem exigir uma nova versao do mod.

ENGLISH
-------
Makes NPC recruitment and management (Community, version 1.1) work on dedicated servers.
The client side is a single pak: the game executable is not modified.

Install
- Vortex: use the "Mod Manager Download" button ("HumanitZ Vortex Extension").
- Manual: copy NPCCommunityFix_Client_P.pak to ...\HumanitZ\HumanitZ\Content\Paks\~mods\
  (create the ~mods folder if it does not exist).

Requirements
- The server must run the server part of this mod, same version.
- Single-player and games you host keep working normally with the mod installed.

IMPORTANT
- Disable/remove the mod before joining servers without it (official or third-party): the mod changes how
  community data is replicated and connecting to an unmodded server may fail.
- Game updates may require a new mod version.
