NPC Mechanics - Player Camera Freedom patch (optional)

EN
Only for players who use BOTH "NPC Mechanics" (client) and "Player and Vehicle Camera - Unlocked" by XEM122 (Nexus HumanitZ mod 106).
Both mods replace the same game file (BP_CharacterBase), so only one of them works. This patch is the NPC Mechanics file with the same
on-foot camera changes as PlayerCameraFreedom (camera can tilt to the horizon: pitch limits -89/89, CameraTilt 0, OutDoorAngle -5).
Install: put NPCMechanics_CameraFreedomPatch_9_P.pak in HumanitZ\Content\Paks\~mods and REMOVE PlayerCameraFreedom_P.pak
(keep the vehicle camera file from mod 106 if you use it; it does not conflict). Requires NPC Mechanics client 1.0.9 (this patch is built on that exact file; when NPC Mechanics updates its client,
use the patch with the same version number). Client only: the server needs nothing.
Credits: camera values and idea by XEM122 (Player and Vehicle Camera - Unlocked).

PT
Só para quem usa o "NPC Mechanics" (cliente) JUNTO com o "Player and Vehicle Camera - Unlocked" do XEM122 (Nexus HumanitZ, mod 106).
Os dois trocam o mesmo arquivo do jogo (BP_CharacterBase) e só um funciona. Este patch é o arquivo do NPC Mechanics com as mesmas
mudanças de câmera a pé do PlayerCameraFreedom (câmera inclina até o horizonte: limites -89/89, CameraTilt 0, OutDoorAngle -5).
Instalar: coloque NPCMechanics_CameraFreedomPatch_9_P.pak em HumanitZ\Content\Paks\~mods e TIRE o PlayerCameraFreedom_P.pak
(o arquivo de câmera de veículo do mod 106 pode ficar; ele não conflita). Precisa do cliente do NPC Mechanics 1.0.9 (o patch é feito sobre esse arquivo; quando o cliente do NPC Mechanics mudar,
use o patch com o mesmo número de versão). Só no cliente: o servidor não precisa de nada.
Créditos: valores e ideia da câmera do XEM122 (Player and Vehicle Camera - Unlocked).
